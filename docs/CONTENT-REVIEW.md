# Facts for a teacher to check

All 360 modules were rewritten as professional lessons (no made-up characters, real explained content, seven questions that go from recall to opinion, and seven `answerHints` that the coach reads). They were written with AI help. The tests check reading level, question shape, what each goal needs and that no module names a made-up person (see [CONTENT-GUIDE.md](CONTENT-GUIDE.md)). They cannot check that a fact is true.

Please have a teacher read the modules for each subject and tick each line when it is checked. These are the points the writers were least sure of. The under-13 modules in particular need a teacher or a parent.

Some passages sit close to the edge of their reading-level band (for example the under-13 advanced passages, which need fairly formal words to reach the band). A teacher may want to simplify these, then run the content tests again.
